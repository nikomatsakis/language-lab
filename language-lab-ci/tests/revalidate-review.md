# Independent revalidate forward test

Performed by the tutor-skill subagent on three isolated repositories under
`/tmp/language-lab-revalidate-forward-1/`. The evaluator received the skill and
fixture locations, not expected decisions; it did not inspect the fixture
generator or the checker implementation before making decisions.

## Checklist recorded before implementation inspection

The exact extracted requirement was: “For an integer input, clamp must return
zero below zero, ten above ten, and the input unchanged from zero through ten
inclusive.”

The evaluator enumerated negative inputs including large negatives, zero,
interior integers one through nine, ten, and values above ten including large
positives. Implementation and meaningful test assertions were required for each
partition. Noninteger input is outside this requirement.

## Actions and results

For each fixture the evaluator ran the documented `requirements --requirement
sample.clamp` command, removed any existing evidence, and only then inspected
implementation.py and tests/test_clamp.py. It ran `python3 -m unittest discover
-s tests -v` in each fixture.

- **complete:** The implementation is `max(0, min(10, value))`. Tests assert
  negative/positive extremes, -1, 0, 1, 9, 10, and 11. One test with eight subcases
  passed. A further executed assertion checked all integers in range(11).
  These assertions and the two branch clamps cover every integer partition.
  The evaluator generated exact source/test excerpts with the documented input
  helper, serialized the evidence, and ran the targeted checker successfully.
- **missing-tests:** The same implementation has only the assertion clamp(1)==1.
  Its single test passed, but negative inputs, both boundaries, and upper
  clamping lack assertions. The evaluator refused to create evidence. A passing
  test suite alone was insufficient. This fixture's evidence remains absent.
- **incorrect:** Implementation `min(10, value)` returns negative inputs
  unchanged. The suite failed on -1: actual -1, expected 0. The evaluator refused
  to create evidence and reported the missing lower clamp. This fixture's
  evidence remains absent.

The generated complete evidence uses the three required fields and identifies
both implementation and test excerpts. No production evidence was generated by
this exercise. The freshness checker did not evaluate semantic justification;
that assessment was performed by the independent reviewer.
