# Requirement evidence

Attestations belong here as `<requirement-id>.json`. Use the
[revalidate skill](../.agents/skills/revalidate/SKILL.md) to assess implementation
and tests before creating a file. Missing evidence is an intentional CI failure,
not a reason to fabricate an attestation for unimplemented requirements.

See [language-lab-ci](../language-lab-ci/README.md) for the exact format and commands.
